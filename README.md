# Employee Management System

A Python application for managing employee records, calculating weekly payroll, and handling basic employee management tasks.

## Features

- Add new employees
- Remove employees
- Find employees
- Display employee records
- Calculate total weekly payroll
- Approve manager overtime
- Manage employee information through a terminal menu

## Technologies Used

- Python
- Object-Oriented Programming
- Classes and Objects
- Lists
- Functions
- Loops
- Conditional Logic

## How It Works

The application provides a terminal-based menu that allows users to manage employee information.

Employee records include details such as:

- Employee name
- Employee ID
- Hourly rate
- Hours worked

The application can also calculate the total weekly payroll based on employee hours and hourly rates.
